Web Scraper Dashboard

A Python-based web scraping dashboard that fetches:
- Weather data
- News headlines
- Cryptocurrency prices

Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

Weather Data
  - Fetches current temperatures for major cities using wttr.in

News Headlines
  - Scrapes top headlines from BBC News based on selected categories

  Cryptocurrency Prices
  - Fetches real-time top cryptocurrency prices using CoinGecko API
